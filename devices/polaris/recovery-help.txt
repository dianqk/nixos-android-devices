POLARIS RAM RECOVERY

This image runs from RAM. It does not mount or write partitions on startup.
USB ACM provides a physical root console; NCM/SSH allows passwordless root login by default.
Verify the ephemeral SSH host key through ACM on each recovery boot. The on-screen menu shows the journal and explicit boot actions.

Before using storage, deployment or boot actions, inspect this phone's GPT.
By default, recovery resolves unique system, userdata, boot, recovery and misc
partition names on the built-in UFS and checks filesystem types and labels.
An optional hardware.polaris.storageRolesFile can require exact per-phone
UUID and geometry checks. Normal deployment does not format
or repartition. First installation can explicitly format the existing userdata
partition with recovery format-userdata --confirm; it never edits GPT.

The host-side mobile-device tool provides checked first installation and
updates. Its install-initial action streams a complete system closure and
bootstrap registration onto empty ext4 userdata, selects the first system
profile, installs systemd-boot/kernel/initrd/DTB on FAT /boot, then installs
U-Boot in boot. Polaris installed systems must use this EFI chain. Booting this recovery image
does not install a system by itself.
First installation order (each operation has a read-only check):
recovery format-userdata --check|--confirm
  Explicitly erase existing userdata as ext4, using the configured label.
recovery prepare-boot --check|--confirm
  Prepare physical system as FAT32 /boot after verifying the ext4 store.
  This never changes GPT or super; deploy the EFI system before rebooting.
recovery install-initial MANIFEST REGISTRATION SYSTEM MIN_BYTES --check|--confirm
  Requires empty ext4 userdata and prepared FAT /boot; use mobile-device to
  supply the closure stream. An interrupted install blocks system reboot and
  requires explicit userdata formatting before starting first installation again.

TARGET SYSTEM (no automatic mount or update)
recovery mount-target [--ro|--rw]   Mount root at /mnt and FAT at /mnt/boot (default read-only).
recovery target-status             Check mount identity and selected system.
recovery enter                     Isolated chroot; no activation or target services.
recovery rebuild boot ARGS...      Offline nixos-rebuild boot; switch/test are refused.
recovery unmount-target            Stop store service and unmount (no force/lazy unmount).
Inside recovery enter: nixos-rebuild boot --store-path SYSTEM, or boot --rollback.

FIRST INSTALL (prepared empty ext4 root and FAT boot required)
From host: mobile-device recovery --target HOST install-initial SYSTEM --bootstrap-info INFO
Add --execute after checking. Installs closure, EFI and matching U-Boot; no reboot.
Result: /run/mobile-initial-install.result. See docs/initial-install.md.
