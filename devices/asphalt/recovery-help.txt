Y700 2023 RAM recovery

Connect the USB-C port and run ssh RECOVERY_HOST. SSH/ACM is root; use a trusted host.
Run recovery status to inspect storage before changing it.

Installed systems require U-Boot + systemd-boot and a prepared FAT /boot.
See docs/u-boot-install.md. First installation needs device-specific
storage preparation; format-root only formats the ext4 root and is destructive.

Power and status:
  recovery reboot-system --confirm      Boot NixOS
  recovery reboot-recovery --confirm
  recovery reboot-bootloader --confirm
  recovery poweroff --confirm
  journalctl -b

Hardware diagnostics:
  recovery backlight-id                 Read the KTZ8866 backlight ID

Volume keys select a screen action. Power opens its confirmation.
Experimental U-Boot planning (no partition or filesystem writes):
  recovery plan-uefi 128GiB         # stock GPT: 1 GiB ESP + about 127 GiB root
  recovery plan-uefi existing       # verify a completed EFI layout without writes
The JSON plan includes the current GPT SHA256 and the data-loss scope.
Unknown/partial layouts are refused; completed layouts return action=none.
Do not apply this plan until U-Boot hardware bring-up and installation gates are verified.

TARGET SYSTEM (no automatic mount or update)
recovery mount-target [--ro|--rw]   Mount root at /mnt and FAT at /mnt/boot (default read-only).
recovery target-status             Check mount identity and selected system.
recovery enter                     Isolated chroot; no activation or target services.
recovery rebuild boot ARGS...      Offline nixos-rebuild boot; switch/test are refused.
recovery unmount-target            Stop store service and unmount (no force/lazy unmount).
Inside recovery enter: nixos-rebuild boot --store-path SYSTEM, or boot --rollback.

FIRST INSTALL (prepared empty ext4 root and FAT boot required)
From host: mobile-device recovery --target HOST install-initial SYSTEM --bootstrap-info INFO
Add --execute after checking. Installs closure, EFI and matching U-Boot; no reboot.
Result: /run/mobile-initial-install.result. See docs/initial-install.md.
